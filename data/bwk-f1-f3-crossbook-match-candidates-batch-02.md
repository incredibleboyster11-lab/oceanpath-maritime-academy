## 3. Source differences and QA flags

1. BWK E14 combines NLS spill response and a chemical-tanker cargo-space fire scenario. F3 Q18 is a forward-store/paint-locker fire; these are not interchangeable.
2. BWK E12 describes an operational CO2 release sequence. F3 Q9/Q12 describe line testing and system requirements; do not substitute one for the other.
3. BWK E10's abandonment procedure and F3 Q11's drill schedule have different purposes and should remain distinct.
4. The audit records what the books say. It does not certify technical correctness, regulatory currency or suitability for a live shipboard procedure.

## 4. Regulatory currency lead: Polar Code

The IMO's official amendments page lists MSC.538(107) Polar Code amendments effective 1 January 2026. The IMO January 2026 Polar Code supplement identifies amendments to Part I-A Chapter 9, while the IMO status document confirms entry into force. The amendments concern additional categories of vessels and must be assessed by vessel type, tonnage, voyage and construction date. The source books' general equipment summaries should not be silently rewritten as universally applicable requirements.
