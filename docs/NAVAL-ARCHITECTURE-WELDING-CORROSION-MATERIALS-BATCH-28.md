## 4. QA / safety / regulatory boundaries

- Welding procedures, welder qualification, NDT methods and acceptance criteria must be checked against applicable class rules, approved procedures and current standards before publication.
- Do not treat a generic NDT method as suitable for every weld geometry or defect.
- Galvanic-series order and compatibility depend on electrolyte / environment and actual alloy condition; verify the precise table used in the source before creating a public memory chart.
- Cathodic protection is not a universal substitute for coating, electrical isolation or proper joint design.
- Aluminium-to-steel joint details are safety-critical structural content and need qualified naval-architect / class review.
- MSDS/SDS content should be checked against current product-specific safety data, not generic paint notes.
- Preserve source corrections and historical exam framing separately from current technical update notes.
