## 4. Cross-book integration candidates (structural only)

These are topic-name overlaps visible in the indexes, not yet verified duplicate question matches:

- **Stability / damage stability:** NA1, NA, F2 T1, F3 T5.
- **COLREG / watchkeeping / bridge operations:** F1 T1 and T9, BWK topics 1/9, with related NAV topics.
- **Cargo operations:** F2 T2–T9, especially IMSBC, Grain, IMDG and cargo securing; related BWK ship handling and F3 compliance topics.
- **MARPOL / BWM / environmental compliance:** LAW, F3 T2 and F3 T9; MEK pollution-control topic.
- **SOLAS / STCW / ISM:** LAW, F1 T9, F3 T3/T4 and NA/MEK fire or machinery topics.
- **Ship handling / anchoring / mooring / tugs:** BWK, F1 T7, F2 T1/T7 and F3 T7.
- **Legislation and conventions:** LAW provides the written-answer/reference-list structure; F1/F2/F3 contain oral question counterparts.
- **Numerical stability / hydrostatics:** NA1 and NA; numerical types should remain separate until formulas, assumptions and source question identities are compared.

## 5. Migration model proposed

Use a single canonical learning-unit record with these source-derived dimensions:

- `source_book_code`, `source_filename`, `source_page_start`, `source_page_end`
- `stage` (Phase I written / Phase II written / oral Function 1/2/3)
- `subject`, `topic_id`, `topic_title`, `source_question_id` (when present in the book)
- `content_type` (theory answer / oral Q&A / numerical / sketch / reference list / past-paper crosswalk)
- `source_priority_label` and `source_frequency_label` kept as source claims, not platform predictions
- `rights_status`, `privacy_review_status`, `technical_review_status`, `regulatory_review_status`
- `publication_status` initially `draft`; canonical public route assigned only after all gates pass
- `provenance_notes` and `change_history`

Do not merge two units merely because their topic titles look similar. Match only after comparing the actual question wording, answer coverage, marks, assumptions, figures, diagrams and paper references. Preserve separate written and oral versions where the examination task differs.

## 6. Known limitations and next actions

1. This pass transcribed topic-level indexes from the PDFs; it has not extracted every question-level ID or every answer page.
2. Source-declared counts need reconciliation. Some index totals may not equal cover metrics because of notes, subparts, added answers or source-specific counting conventions.
3. Cross-book overlaps above are candidate links only; no duplicate question claims are made.
4. Surveyor-profile and oral-report-derived details remain excluded from public migration pending privacy/confidentiality review.
5. Past-paper reproduction and embedded third-party material require component-level rights review.
6. Technical and regulatory accuracy must be reviewed against current official references before publication.
