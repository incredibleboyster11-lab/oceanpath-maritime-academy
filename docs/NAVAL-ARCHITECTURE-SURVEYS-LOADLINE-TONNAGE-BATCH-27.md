## 4. Current regulatory update hooks from official / authoritative research

### ESP Code — effective 1 January 2026
IMO states that amendments to the 2011 ESP Code relate to Administration oversight of firms conducting hull-structure thickness measurements on bulk carriers and oil tankers, including audits of those firms. This is a direct update hook for NA I V01/V05/V09. The user book's source-era answer should remain preserved as written; add a separate dated update note after qualified review. Source: IMO, “Raft of shipping rules in force from 1 January 2026.” https://www.imo.org/en/mediacentre/pressbriefings/pages/raft-of-shipping-rules-in-force-from-1-january-2026.aspx

### 2026 amendments affecting survey / certification ecosystem
IMO's amendment calendar lists the 2026 effective dates and relevant resolutions. It identifies MSC.553(108) for ESP Code amendments effective 1 January 2026. Source: IMO amendments to instruments page. https://www.imo.org/en/about/conventions/pages/amendments-to-imo-instruments.aspx

### Load Line / tonnage
This batch does not attempt to recalculate freeboard, update zone/season tables or re-derive ITC 1969 tonnage formulae. Verify controlled current convention text, amendments, flag implementation and the vessel's certificates before publishing.
