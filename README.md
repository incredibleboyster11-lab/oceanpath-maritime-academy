# OceanPath Maritime Academy

A free, independent maritime learning platform for seafarers. The initial focus is Deck Officer learning pathways.

## Public release scope
This repository contains only the public-facing static website pages and deployment workflow. It does not contain original study repositories, draft answer banks, private source material, or personal learner data.

## Pages
- `index.html` — homepage
- `learning.html` — learning pathways
- `library.html` — publication-status library
- `privacy.html` — privacy status and commitments
- `corrections.html` — corrections and exam integrity

## Deployment
GitHub Actions deploys the repository root to GitHub Pages when `main` changes. Enable Pages in repository Settings → Pages → Source: GitHub Actions.

## Important
OceanPath Maritime Academy is a working brand name only. It is an independent learning resource, not a DG Shipping, MMD, IMU or government portal and does not issue Certificates of Competency. No registration or personal-data collection is implemented.
